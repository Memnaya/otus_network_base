## Вопрос для повторения

**Почему маска подсети так важна при анализе IPv4-адреса?**

**Ответ:**  
Маска определяет, какая часть IPv4-адреса относится к сети (и подсети), а какая — к узлу. Без маски невозможно понять, принадлежит ли адрес локальной сети, как маршрутизировать трафик и где находятся границы подсети. Она позволяет вычислить сетевой адрес, широковещательный адрес, диапазон допустимых адресов узлов и количество доступных хостов в подсети.
