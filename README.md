# OTUS Сетевой инженер. Базовый уровень

Хранилище лабораторных работ по курсу OTUS "Сетевой инженер. Базовый уровень".

## Используемое ПО

| Компонент | Назначение |
|-----------|------------|
| **EVE-NG** | Эмуляция сетевого оборудования |
| **Cisco IOS** | Операционная система коммутаторов/маршрутизаторов |
| **Tiny Core Linux** | Клиентские ПК для тестирования |
| **Telnet / SSH** | Удаленное управление устройствами |
